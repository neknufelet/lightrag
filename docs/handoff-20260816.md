## 1.4 ⚠ 那把「漏詞率」的尺，主要在量它自己壞掉

**這是今天最重要的一課，寫在最前面免得下一個人重踩。**

它的算法是「PDF 文字層有的詞」減「解析結果有的詞」。**兩個母體，而壞的一直是
對照組那一邊。** 15 份超標裡 5 份已逐份查證過，全部是假訊號，**五種不同的壞法**：

| 文件 | 漏詞率 | 真正的原因 |
|---|---:|---|
| 2023 Differentiable Image Source | 79.1% | IEEE 頁側直式浮水印被 `pdftotext` 讀成逐字母碎片（`A c o usti cs` → `usti`）。對照組只讀出 397 詞而解析抽出 2,500 |
| 2024 A Compact… Folded Slit | 28.9% | 雙欄版面讓 `pdftotext` 把同段輸出兩次。**缺詞第一名是 `the`（336 次）—— 冠詞不可能被漏掉** |
| 1979 Image method | 11.5% | 1979 掃描件的文字層沒有詞邊界（`room acoustics` → `roomacoustics`） |
| C Equivalent Networks | 10.5% | 已逐詞歸因：表格黏連 117 詞、圖裡 73 詞、bbox 未覆蓋 91 詞 |
| 2026 On Efficient Algorithm | 10.2% | 數學字型沒有可用編碼，`pdftotext` 吐 `dddd`／`nnjj`／`mmmmmm` |

⇒ **壞的方向是單向的：對照組讀壞 → 漏詞率被推高。**

## 2.2 修掉的是什麼：∂ 被讀成別的字母

```
∂Π/∂x      被存成   Ô x           分母的 ∂ 變成花體 O 戴帽子
∂²/∂t²     被存成   D̂²/Ô t²      分子分母各錯成不同的字母
∂/∂x       被存成   ∂̂/∂x          多戴一頂帽子
∂τ         被存成   δτ            ∂ 變成 δ
```

**這不是排版，是內容錯了**，而且這些文字就是餵給 AI 的原料。

```
合併前  N Flow 的 chunk：5 段含 A、3 段含 B、1 段含 C；全庫 2 份中招
合併後  N Flow 0／0／0（103 chunk）；全庫 1 份中招
```

⚠ **查它不能用 `LIKE`**：PostgreSQL 的 `LIKE` 預設拿反斜線當跳脫字元，
`'%\hat { \sigma }%'` 實際比對 `hat { sigma }`，**回 0 而且不報錯**。用 `strpos`。

驗收：實查一題 Lighthill 張量，回來的公式是正確的 `∂²/∂x_i∂x_j`。

**三條路：**

| | 做法 | 缺點 |
|---|---|---|
| A | 你繼續自己切 | 手工、切點沒紀錄、你要記得拿掉前言 |

# 第五部分：⚠ 動手前必讀（血淚）

1. **Zotero 的 `DELETE /tags?tag=X` 不分大小寫** —— 刪 `_RAGED` 會把 `_Raged`
   一起帶走。08-14 誤刪 163 筆。**永遠用逐筆 PATCH，動之前先存備份。**
2. **標籤要寫成 type 0（手動）**。type 1 會被「刪除所有自動標籤」清光。
3. **Zotero 自己會砍附件檔名**，砍在 110–111 字，**一律砍尾巴**。
4. **kbapi 的 `/docs` 讀的是 `work/parsed`，不是圖譜。** 刪掉圖譜裡的文件之後
   它照樣列著，解析包要一併移走。
5. **從 Zotero 重送已入庫的檔案沒用** —— 伺服器比對內容雜湊，會回 409。
6. **冷備的「還原」從來沒有人走過**，不能當安全網。回滾要靠「指回舊庫」。
7. **帶反斜線的樣式不能用 SQL 的 `LIKE`** —— 它預設拿 `\` 當跳脫字元，
   **回 0 而且不報錯**。用 `strpos`。（2026-08-16 新增）
8. **`--doc` 是子字串比對**，`"G Porous"` 會抓到
   `2022 - General extended-reactin**g porous** materials…`。
   下 `--commit` 之前先乾跑看它抓到幾份。（2026-08-16 新增）
9. **對一支會叫的尺下裁決之前，先問它自己記了什麼**（`--doc` 會印查證紀錄），
   再看樣本。只看總表末尾幾份會得到錯的結論。（2026-08-16 新增）
10. **`.env` 不要用 `source` 讀**，`LIGHTRAG_PARSER` 的值含 `;`。
    取值用 `grep -E '^KEY=' … | cut -d= -f2-`。
