## 這一天真正學到的東西

### 1. 「乾淨的 0」踩了四次，已升為鐵則 7

四次都**看起來像乾淨的結論**，實際上全是量錯：

| 現象 | 真相 |
|---|---|
| SQL 測試綠、實跑死 | 測試斷言的是**字串字面**有 `:'workspace'`；壞的是 `psql -c` 不展開變數 |
| 命名探針兩組都 0 個實體 | 解析器用 `<\|>` 格式，但 LightRAG 走 **JSON** ——控制組本來就該重現既有結果 |
| 三組實體數全 0 | `chunk_ids` 是**陣列欄位**，用單數 `chunk_id` join |
| `nginx -t` 成功、reload 成功、但設定沒生效 | **`sed -i` 換 inode**，bind mount 綁的是舊 inode，容器看到的還是舊檔 |

最後一個最陰險：**兩個綠燈都是真的，它們只是驗了舊檔**。

對策已寫進工具：**「這個數字若為 0，先當成壞了，印出警告，不要輸出結論」**。
判準一句話——**控制組本來就該重現既有結果，重現不了就是量錯**。

### 2. 沒驗過的東西等於沒有

同一個形狀出現三次：

- **備份沒驗過還原 = 沒有備份** → 做了演練，通過
- **警報沒驗過送達 = 沒有警報** → 發了測試，PO 確認收到
- **兩份快照看起來是兩個還原點** → `restic diff` 回 0，**逐位元相同**，實際只有一個

第三條特別值得記：我一整天都在報「有兩份快照」，直到去比對才發現那是同一份上傳兩次。

### 3. 對抗式審查擋掉了四個會誤導的結論

`symbol-hits.py` 被終審擋了三次、工單被單審擋一次，每次擋的都是真東西：

- 有請求失敗時仍算出 tok/s（分子少了、分母照算）

- 統計誤述：把「小樣本沒偵測到差異」講成「沒有差異」

而且**設計席（fable）反過來糾正了終審（sol）兩點統計判斷**，單審裁定設計席對。
沒有人驗自己這條規則，在這一天產生了實際價值。

`Brota`／`V11x`／`P11`／`L A` 都是上游解析錯誤被忠實抄進索引。

**先講一個讓這一族至今沒被抓到的性質**：**它對接地檢查是隱形的。**
`Brota Parameters` 能對上原文——因為**原文本身就被污染了**（`BroT's parameters`
真的在裡面）。所以它永遠不會進「可疑」清單。偵測器必須看**原文**，
不能看「實體 vs 原文」的比對。

**規模（`$RECORDS/review/20260803-speedup-symbol3/ocr_sizing.py`，母體 7,211 個實體名）**：

```
數字 11/111（羅馬 II/III 誤讀）   17 個　例全為真：Z0 V11x、Pressure Field p11、Acoustic Pressure P11
字母數字黏連（V11x 型）            4 個　其中 T33s/T13s 是應力張量分量，正常寫法
詞中大寫（BroT 型）               27 個　多半是符號音譯不是 OCR 壞字
孤立單字母（Γ→L 型）             695 個　**幾乎全是雜訊**：Maximum Distance R Max、Epsilon I 都是正常命名
```
