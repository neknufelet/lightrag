## PO 2026-08-17 裁的四條

### 一、打勾 ＝ 不要

打勾代表「這段不要進知識庫」。**要丟掉的比較多**，所以這樣人動手的次數少。

### 二、一份一份，但不用做完才能往下；**確認一份、放行一份**

- 每做完一份**存一次**，關掉瀏覽器不會丟；回來從那一份接著。
- **確認完的積起來，湊成一批就去抽取。** 不用等 165 份全部做完。
- **沒確認的等著，不會被抽取。**

⚠ **這一條是 2026-08-17 稍晚更正的。** 模擬畫面第一版我寫了
「沒做完不擋新庫，文件照樣進得去」—— **那是我自己加的，沒想清楚成本，是錯的。**
PO 問「是做完全部才抽，還是決定多少抽多少」時才發現。

**為什麼「先抽再確認」是錯的**：消音會改變送去抽取的文字（`pp/apply.py` 的註解
寫著消音會讓 `is_bundle_valid = False`、快取失效）。先抽了之後才改消音，
那一份就得**重抽一次** —— 而抽取是整條線最貴的一步（審核台自己的字：
「先花小錢解析看清楚，再花十幾分鐘抽取的大錢」）。

⇒ 先抽再確認 ＝ 花兩次錢，165 份全改就是全部重來。

⚠ PO 明確否決了「按型別整批決定」那個版本（那會把 631 個決定壓成 5 個，
但他要一份一份）。**那個選項留在這裡備查，不要當成沒提過**：
如果哪天覺得太慢，改成按型別是現成的加速路。

### 三、不確定的預設不勾（＝留著）

寧可多留垃圾，不要誤刪正文。與 `docs/hard-rules.md` 一貫。

### 四、⭐ 每一項都要有一句白話說明「為什麼」

**PO 2026-08-17 看過模擬之後主動指名要保留這個。** 例如：

```
參考書目    機器有把握，先幫你勾了
期刊封面頁  整頁只有刊名與投稿日期
不確定      像頁首，但裡面有數字
致謝        不敢消，有些致謝裡寫著資料來源
```

**為什麼這條值得單獨記**：沒有這句話的話，畫面只剩「一堆勾選框加一堆文字」，
人得自己重新判斷每一項 —— 那就等於規則沒幫上忙。
這句話是「規則先幫你勾好」這個設計**能不能省下人力的關鍵**，不是裝飾。

⚠ 說明文字要說**理由**不是說**分類**。「參考書目」是分類，
「機器有把握，先幫你勾了」才是理由 —— 兩個都要，因為人要判斷的是
「機器憑什麼這樣勾」。

## 每一項要顯示什麼（模擬畫面的結論）

| 欄位 | 例 | 為什麼要 |
|---|---|---|
| 勾選框 | ☑ | 預設值由規則決定 |
| 分類 | `參考書目` | 一眼分辨同型的 |
| **理由** | `機器有把握，先幫你勾了` | **第四條，關鍵** |
| 原文片段 | `[1] J. Christensen…` | 不看原文沒辦法判斷 |
| 位置 | `第 8 頁` | 要回頭查得到 |
| 佐證數字 | `參考書目佔 32.4%（平常 15–20%）` | 有量到的就給，讓人自己判斷嚴重度 |

⚠ 最後一列是今天稍早那個教訓的延伸：`ledger.py` 曾把嚴重程度寫死成形容詞，
實際差六百倍。**有數字就給數字，不要用形容詞替人下結論。**
