# 動手前必讀

1. **數字先自己量一次。** 這份文件的數字是 2026-08-21 深夜量的，
   重量指令在 [handoff-20260821](handoff-20260821.md)。
2. **改完要交四行**：改了什麼／**沒改什麼**／沒驗什麼／會壞什麼。第二行最重要。
3. **凡是關於跑著的系統的陳述，一律附 dker 的實跑輸出**（藍桶第 9 條）。
   coder 上沒有 `.env` 也沒有 docker，「我在 coder 上驗過了」在物理上做不到。
4. **改了判準要能證明它會紅。** 不是要你補那 50 盞，是**你這次動到的那一盞**：
   故意弄壞 → 看它紅 → 改回來 → 看它綠 → 拿一個相似但不該觸發的情境 → 不紅。
   ⚠ 只驗「壞的會紅」等於沒驗。
