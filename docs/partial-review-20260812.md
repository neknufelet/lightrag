# ∂ 誤讀逐處判讀（2026-08-12）

MinerU 把 `∂` 的曲線讀成「某個字母戴帽子」。它**不刪字、不改型別**，所以漏字檢查
（覆蓋率永遠 100%）與 preflight（型別沒變）都抓不到，可以完全安靜地進索引。

**現況：71 處、8 種 token、20 個「文件 × 符號」組合。**要重跑就跑，數字不抄在這裡：

```
ssh 100.87.88.7 'cd ~/ghq/github.com/neknufelet/lightrag && python3 scripts/scan-partial.py --details'
```

⚠ **本文件寫的時候一個字都還沒改。**

## 兩處疑義：看原圖解決的，沒有花任何 API 費用

先前這兩組是「留手」，因為只看 LaTeX 判不出來。**裁出那兩塊看原始像素就結案了。**

### `N Flow Acoustics` 第 942 項的 `D̂`（5 處）→ 全部是 ∂

疑義在於：物質導數 `D/Dt` 在流動聲學裡是真的存在，而這一段正是對流波動方程式。

原圖（第 38 頁）：

```
∂²B'/∂x_i² − { 1/c² [ ∂²/∂t² + ( 2v_i ∂/∂t − (v⃗×ω⃗)_i − 2 ∂h/∂x_i ) ∂/∂x_i
             + v_i v_j ∂²/∂x_i∂x_j ] B' }'
  = { [ ∂/∂x_i − 1/c² ( −(v⃗×ω⃗)_i − 2 ∂h/∂x_i + v_i v_j ∂/∂x_i ) ]
      · ( (v⃗×ω⃗)'_j + ‾[∂v'_i/∂t] ) }' + [ ∂/∂t (1/c²)' Dh/Dt ]'
```

⇒ 被報出來的那五個位置，原圖上**全部是 ∂**。

⚠ **而同一條式子的最後真的有一個物質導數 `Dh/Dt`** —— 直立的 D、沒有帽子。
`scan-partial.py` 舊白名單寫的「#942 真物質導數」指的就是它，探針本來就不會報它
（`\mathrm{D}` 不是 accent）。**兩者在同一條式子裡並存** —— 所以「這份文件有物質導數」
不能拿來當「這些 D̂ 是物質導數」的理由。

### `∂̄`（3 處）→ 把多出來的槓拿掉

原圖（第 8 頁）：

```
ρ̄ ∂v'_i/∂t  +  ‾‾‾‾  ∂v'_i/∂x_j  +  ∂p'/∂x_i = 0
                ρv_j
```

橫槓蓋在 **`ρv_j`** 上面（平均值），**∂ 上面乾乾淨淨**。
MinerU 把那條槓錯配到 ∂ 身上 ⇒ 拿掉是對的。

⚠ 這一組的改法跟其他不同：其他是「把讀錯的字母換成 `\partial`」，
這裡是「**把 ∂ 上面多出來的槓拿掉**」。

⇒ 順帶記一個**不在這次範圍**的錯：MinerU 把 `\overline{ρv_j}` 的槓只蓋在 ρ 上
（`\overline{{\mathsf{P}}}\mathbf{v_j}`），槓的範圍縮小了。那是另一類錯誤。

### 這一步的教訓

兩組疑義都是**看一眼原圖就結案**，而我原本打算叫兩隻模型來投票。
⇒ **有原圖可看的時候，先看原圖。** 模型投票是給「看了也還是不確定」的情況用的。

## 探針還抓不到的一類：同一個 ∂ 被讀成兩個不同字母

```
第 942 項：  \frac{ D̂ }{ Ô x_i }         分子 D̂、分母 Ô
第 802 項：  \frac{ v̂O² }{ σ̂ t² }        分子 v̂O、分母 σ̂
O 那份 #782：\frac{ ĉ g(x,y) }{ α̂ n(y) }  分子 ĉ、分母 α̂
```

**上下同形這條規則永遠看不到它們**，因為兩側不同形。

⚠ **不要靠放寬這條規則去抓。** 放寬等於「任何 accent 對 accent 的分數都算導數」，
而真的比值就是長那樣（Favre、Biot 那兩個誤報都是這個形狀）。
要抓得另立判準 —— 例如「這份文件已經確定有 ∂ 誤讀，而且分母的被微分量是座標或時間」。

**現在的處置：記在這裡，不動。** 這一類的量還沒數過。
