$= a^2 \frac{(\eta_n a) J_0(\varepsilon_m a) J_1(\eta_n a)}{(\eta_n a)^2 - (\varepsilon_m a)^2}$
$\underset{n=0, m\neq0}{\longrightarrow} 0 \ ; \quad \underset{n=0, m=0}{\longrightarrow} \frac{a^2}{2} \ ; \quad \underset{m=0}{\longrightarrow} a^2 \frac{J_1(\eta_n a)}{(\eta_n a)}$

$Z_{\text{sh}} = \frac{\langle p_{\text{I}}(0, r) \rangle_a}{\langle Z_0 v_{\text{Ix}}(0, r) \rangle_a} = \frac{\langle B_0 + C_0 \rangle_a}{\langle B_0 - C_0 \rangle_a} = \frac{1 + C_0/B_0}{1 - C_0/B_0}$
