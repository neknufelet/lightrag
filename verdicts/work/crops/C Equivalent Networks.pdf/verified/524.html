Equation for $C_0$ $C_0/B_0 = \left[ -1 + \frac{j}{4a^2} \sum_{n,v \ge 0} \frac{(S_n^v)^2 \coth(\gamma_{n,v}t)}{(\gamma_{n,v}/k_0) N_{n,v}^{(II)}} \right] \times \left[ 1 + \frac{j}{4a^2} \sum_{n,v \ge 0} \frac{(S_n^v)^2 \coth(\gamma_{n,v}t)}{(\gamma_{n,v}/k_0) N_{n,v}^{(II)}} \right]^{-1}$
Equations for $D_{n,v}$ $D_{n,v} = j \frac{S_n^v}{(\gamma_{n,v}/k_0) \sinh(\gamma_{n,v}t) N_{n,v}^{(II)}} (B_0 - C_0)$
Mode norms in (II) $N_{n,v}^{(II)} = N_{y,n}^{(II)} \cdot N_{z,v}^{(II)}$   ;   $N_{y,n}^{(II)} = \begin{cases} b & ; n \neq 0 \\ 2b & ; n = 0 \end{cases}$ ;

$N_{z,v}^{(II)} = \begin{cases} c & ; v \neq 0 \\ 2c & ; v = 0 \end{cases}$
Mode coupling (I)–(II) in s = $4a^2$ $S_n^v = \int_{-a}^{+a} \int_{-a}^{+a} \cos(\eta_n y) \cos(\chi_v z) \, dy \, dz$
$= \begin{cases} 2a & ; n = 0 \\ a & ; n \neq 0 \end{cases} \times \begin{cases} 2a & ; v = 0 \\ a & ; v \neq 0 \end{cases}$
Orifice partition impedance $Z_{Mi} = Z_{sh} - \sigma \cdot \underline{Z}_K$   ;   $\underline{Z}_K = -j \cot(k_0 t)$

$Z_{sh} = \frac{\langle p_I(0, r) \rangle_s}{\langle Z_0 v_{I_x}(0, r) \rangle_s} = \frac{1 + C_0/B_0}{1 - C_0/B_0}$
