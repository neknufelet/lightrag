## 1. 為什麼一張都沒寫：兩道**現行規則**擋在前面

工單要求「補入（經 `gate_table_html`，寫入走 apply 與 verified 裁定檔）」。
照做時撞到兩件事，兩件都不是我可以自己決定的：

### 1.1 `apply.py` 拒絕寫「已經有內容」的表格

`empty_table.plan()` 現在對 C 回報 **可修補 0 張**（10 張空表在階段 2 修完，
已不再是空表；其餘 47 張 `classify` 全是 `ok`）。`apply_doc()` 的判準是：

```
missing_tbl = set(want) - repairable_idx - done_tbl
if missing_tbl: raise ApplyError("…不在可修補集合裡…先重跑 plan")
```

把 #405／#529／#520 這種 `ok` 表格放進 `verified/`，**整批 20 份會直接失敗**。

這條不是防呆，是**耐久規則**：`empty_table.py` 的檔頭記著它的證據
（idx 7 是完整五欄表、799 字元實質內容，「拿 VLM 的猜測覆蓋它，就是製造本專案
一路在防的那種靜默損壞」）。工單的「已存在的 table_body 內部補格」與這條規則
**直接衝突**，要動它就是動一條有證據的耐久規則 —— 依 CLAUDE.md 要走
「改 → canary（預期失敗）→ 逐條確認每個漂移都是想要的 → `canary --update`」，
而且要有人為每個數字變動負責。

### 1.2 `gate_table_html` 拒絕任何 `<img>`，包括 MinerU 自己的

C 有 26 張表的現值帶 `<img src="images/<sha>.jpg">`（MinerU 抽出來的電路符號圖，
檔案真的在 bundle 裡）。定點補格必須「現值對的格一個字不動」＝ 保留那些 `<img>`，
但 `gate_table_html` 見到 `<img` 就 `sys.exit`。

閘門的本意是擋**捏造**的圖片參照（C #525 的 imgur 網址，本輪又抓到 8 張），
不是擋 MinerU 既有的本地參照。但「保留既有本地 `images/` 參照」與「拒絕一切 `<img>`」
是兩條不同的規則，改哪一條、怎麼改，是主線的裁決。

**受這條影響的修補：#520（19 詞，本輪最大一筆）、#454（4 詞）、#373（3 詞）。**

三個詞全部記成漏。同族的還有 `tanh`（25 次，最大單詞）——
現值寫成 `\mathsf { t a n h }` 之類的逐字母排版。

> **這推翻了工單對殘餘 12.0% 的歸因。** 工單說「殘餘的流失發生在已存在的
> table_body 內部（tanh／viix 這類公式內容）」—— 前半對（確實在 table_body 內部），
> 但 `tanh` 這一類**內容沒有掉**，掉的是分隔符。它是 MinerU 的缺陷（對索引有害：
> 檢索 "Resistor" 配不到 `resistorcapacitorcoil`），但它的修法是**重排結構**，
> 不是補格；而重排結構＝整表換掉，正是工單明令不做的事。

### 2.1 `viix`／`iiix` 不是漏字，是 `\times` 誤讀（新發現）

全庫漏詞榜上的 `viix(23)` 與本檔的 `iiix` 一直被當成「公式內容流失」。
實測不是：MinerU 把下標的 `x` 讀成了 `\times`。

```
現值   Z _ { 0 } \mathsf { v } _ { \mathsf { I } \times } ( \mathsf { x } )
裁圖   Z₀ v_{Ix}(x)
```

C 有 25 個項目共 51 處 `\times`，其中「緊接在區域羅馬數字下標之後」的那些全是這個誤讀
（#520 ×5、#529 ×5、#431 ×4、#373 ×2 …）。

**這是一個和 ∂ 族完全同型的機械修補候選**：位置錨定（`_{\mathsf{I|II|III}\times}`）、
零例外可驗、免費掃描。不在本工單授權範圍，列在這裡當下一張工單的材料。

## 7. 定案（主線裁決，2026-08-02 晚，依使用者「能救多少救多少」的授權）

1. **§1.2 照准，窄改**：`gate_table_html` 容許**與現值逐位元相同的既有本地
   `images/…` 參照**；外部網址與任何「新增的」`<img>` 照舊拒絕。
   閘門的目的（擋捏造）不變——本輪 qwen 又交出 8 個 imgur 網址，證明閘門的
   存在理由，也證明「既有本地參照」與「捏造參照」是兩種東西。
2. **§1.1 照准，但不放寬耐久規則本身**：`empty_table` 的「不得覆蓋非空表格」
   原樣保留（idx 7 的證據還在）。另開一條**只加不改**的 curated 補格路徑：
   verified 裁定檔只能「填空格／在截斷格前接前綴／新增格」，**現值非空的
   位元組一個都不准動**，寫入前 diff 驗證。走 canary 流程。
3. **五筆補格全數照准**：#520、#405（只補前綴）、#529 r1c0＋r4c0（r2c0／r5c0
   不補，照提案）、#454（羅馬數字下標採 luna）、#373。約 39 詞。
4. **`viix`／`\times` 誤讀**：核可為機械修補候選。錨定
   `_{\mathsf{I|II|III}\times}` 掃全母體＋抽 3 張裁圖驗證，零例外才套，
   一個反例就逐條清單。
5. **glued/spaced**：`\mathsf{t a n h}` 型的**格內逐字母排版**核可為機械正規化
   候選（同 latex_unspace 語意、只動 `\cmd{…}` 引數內、保留 `_pp_original_text`、
   零例外掃描）；`ResistorCapacitorCoil` 型的**結構黏連**不在後處理射程，
   記 NEXT 當解析階段議題。
6. qwen 的 `<img>` 捏造行為（24/57、8 imgur）記入 `model-observations.json`。
